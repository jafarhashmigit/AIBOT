# Phase 11 limitations

1. Validation only. No model training. No combined learning.
2. Paper completed outcomes remain zero; performance metrics for paper are `null` / unavailable, not zero.
3. Historical hypothetical R is not comparable to paper-trade R. They are different populations.
4. Historical `profit_factor` is descriptive only and is not an economic edge.
5. A future shared learner needs an explicit adapter; Phase 11 does not build it.
6. The Phase 6 WAIT-only RiskGate is unchanged.
7. Holdout and post-cutoff market rows are not accessed.
8. No MT5, live data, broker orders, background services, or package changes.
9. Not production-ready. Not live-trading-ready.
