# Phase 7 policy freeze

Written **before** Phase 7 economic results were computed. Do not edit this file after seeing scores.

This is not a new strategy. It is the Phase 6 default agent run on frozen Phase 2 OOS predictions.

## Champion

Phase 6 champion remains **`no_model`**. That is WAIT-only. Phase 7 does **not** promote a model and does **not** silently turn this into an active strategy.

## Frozen agent (`P7_PHASE6_DEFAULT`)

| Component | Frozen choice | Source |
|---|---|---|
| Predictor | `Phase2PredictorAdapter` — lookup of existing RF OOS `p_tp/p_sl/p_time` and `pred_r_rf` per side. No `fit`. | Phase 2 OOS file |
| Uncertainty | `method=none`, buy=0, sell=0 | Phase 6 `NullPredictor` default |
| DecisionEngine | `DecisionEngine()` with `tau=0`, `min_gap=0.02`, `k=1.0` | Phase 6, not retuned |
| Cost estimate | Frozen $0.25 round-trip (`0.15` spread floor + `$0.05` × 2 sides). Not realized P&L. | `label_m5` / Phase 6 cost version |
| RiskGate | `wait_only=True`, `champion_id=no_model` | Phase 6 default |
| Final decision | `apply_gate(raw, gate)` | Phase 6 |

Expected consequence, accepted in advance: the gate **blocks every BUY/SELL**. Final decisions are **100% WAIT** even if the engine’s raw decision is directional. That is a valid Phase 7 result. The gate will not be weakened to create trades.

NY-SELL, session filters, regime filters, and new thresholds are not part of this policy.

## Frozen baselines (comparison only)

Declared before scoring. Definitions copied from Phases 2–3; not modified after seeing Phase 7 numbers.

1. **Always WAIT** (`A_WAIT`) — every timestamp WAIT.
2. **Phase 2 E1** (`E1_PHASE2`) — side with larger `pred_r_rf` if that value is strictly > 0; else WAIT. At most one side.
3. **Direction** (`B_DIRECTION`) — Phase 3 `baseline_b_direction`: argmax `pred_r_rf` with `tau = -inf` and `min_gap = 0.02`.
4. **Phase 3 frozen conservative EV** (`P3_CONSERVATIVE_EV`) — the Phase 3 selected policy, which froze **Always WAIT** on both nested outer folds. Evaluated as WAIT on WF1–WF3. Inner MAE is **not** re-estimated on Phase 7 OOS.

Baselines are not the agent. They are not used to change the gate.

## What is not chosen from Phase 7 OOS

Thresholds, model, side, confidence, risk rule, cost threshold, session, or any filter.
